PROYECTO XV GABRIELA LISeth · GITHUB PAGES

PUBLICACIÓN
1. Descomprime el ZIP.
2. En el repositorio https://github.com/Jatax81/xv-gabriela abre Add file > Upload files.
3. Sube el CONTENIDO de esta carpeta a la raíz del repositorio (no la carpeta contenedora).
4. Confirma con Commit changes.
5. En Settings > Pages conserva Deploy from a branch, main, /(root).

INVITACIONES
Cada carpeta contiene index.html y tiene el nombre de la invitación como slug.
La dirección de cada invitación se encuentra en el Excel privado de control.

VIDEO
El botón "Cómo llegar al local · Ver video" abre assets/ubicacion-mapale.mp4.
Se conserva también un enlace alternativo a Google Maps.

PRIVACIDAD
No subir el Excel privado de control al repositorio público.
Los enlaces personalizados son direcciones identificables, no contraseñas.
